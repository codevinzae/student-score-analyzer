# Student Score Analyzer

A simple Java GUI made in NetBeans for **DCIT 50 – Object-Oriented Programming**, Lab Activity 2 (Functions & Arrays).

## What it does

Enter a student's name and four scores (Java, Database, Networking, Math), then click **CALCULATE** to see:

- Total score
- Average
- Highest and lowest score
- Result: **PASSED** (75 and above) or **FAILED** (below 75)

The **CLEAR** button resets everything.
